Protocolo de comunicación cliente–servidor (NBA Predictor)

Versión: 1.0 · Transporte: TCP (puerto por defecto 9090)

Describe el protocolo de aplicación (acciones y payloads). La serialización binaria la implementa SocketFrameSerializer en el backend Java. El enrutado de acciones está en SocketDispatcher.

1. Capa de serialización (tramas)

Cada mensaje es: 4 bytes int big-endian (longitud en bytes UTF-8) + cuerpo UTF-8 (JSON).

2. Petición

{
  "requestId": "<string>",
  "action": "<identificador>",
  "payload": { }
}

3. Respuesta

Éxito: ok: true, resultado en data.

Error: ok: false, mensaje en error.
